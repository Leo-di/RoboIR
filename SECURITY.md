# Security Policy

## Supported versions

RoboIR follows the `main` branch and the latest tagged release when available.

## Reporting a vulnerability

If you discover a security issue, please avoid opening a public issue.
Instead, report it privately to the repository owner and include:

- a short summary
- the impacted file or command
- reproduction steps
- any suggested mitigation

## Scope

This project is a robotics and embodied-AI framework, so safety issues may include:

- unsafe adapter behavior
- unexpected execution paths
- malformed plugin or task-pack inputs
- trace or dataset export errors that hide runtime failures
