# 贡献指南

感谢你帮助改进 RoboIR。

## 开始之前

- 以可编辑模式安装项目：`python -m pip install -e .[dev]`
- 运行测试：`pytest`
- 尽量把改动控制在一个扩展面上

## 适合贡献的方向

- `src/roboir/tasks/` 下的新任务包
- `src/roboir/adapters/` 下的新适配器
- `src/roboir_plugins/` 下的新插件
- 让框架更容易上手的新文档或示例

## 风格

- 用清晰的命名，不用花哨缩写
- 尽量保持公共 API 稳定
- 行为变化时补充或更新测试
- 用户流程变化时同步更新 README 或文档

## 建议流程

1. 在本地复现问题
2. 做最小且有用的修改
3. 运行相关测试
4. 必要时更新文档或示例
5. 发起聚焦的拉取请求
